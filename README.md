Checkly is a code-first reliability platform for synthetic monitoring, uptime monitoring, alerting and AI-assisted incident investigation. Engineering teams define monitors as versioned code with the Checkly CLI, Terraform or Pulumi, reuse existing Playwright suites as production browser checks, and run them from 22 global locations or from private locations inside their own network. The platform spans three modules: Detect (uptime, API and browser monitoring), Communicate (alerting, status pages and dashboards) and Resolve (OpenTelemetry tracing and Rocky AI root cause analysis). Checkly exposes a 225-operation public REST API, a hosted MCP server, four published Agent Skills and machine-readable llms.txt, docs and pricing.

**Areas:** Monitoring · Testing · Synthetic Monitoring · Observability · Uptime · Alerting · Status Pages · Monitoring as Code · Playwright · DevOps

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Checkly: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
